# 위젯 화면 구성: 구현 전 질문

[상태 표시 명세](show-state-widget.md)의 **위젯 화면 구성**을 구현하기 전에 정할 사항입니다. 각 질문에서 원하는 항목의 `[ ]`를 `[x]`로 바꾸거나, 질문 번호와 답을 알려 주세요. 추천은 제안이며 아직 결정된 내용이 아닙니다.

## 이미 정해진 조건

- 위쪽에는 흰색 바탕의 짧은 영어 캡션을 Inter 폰트로 한 줄 표시합니다.
- 아래쪽에는 상태 이미지를 256×256 크기의 정사각형으로 표시합니다.
- 전체 화면은 위쪽에 캡션이 있는 밈 이미지처럼 보이게 합니다.
- 상태 전환과 기존의 드래그·우클릭 종료 동작은 그대로 유지합니다.

현재 화면은 이미지 아래에 한국어 상태 문구가 있으므로, 위 조건에 맞게 배치와 문구를 바꾸어야 합니다. Inter 폰트 파일은 현재 저장소에 없으며 이 PC의 Windows 글꼴 폴더에서도 확인되지 않았습니다.

## 답변할 질문

### 1. 상태별로 어떤 캡션을 표시할까요?

아래 문구는 모두 상태가 바뀔 때 이미지와 함께 바뀝니다. `PermissionRequest`는 승인 절차 직전의 신호이므로, 제안한 문구는 실제 승인 화면이 열렸다고 단정하지 않습니다.

- [ ] **A. 아래 문구 사용** — 짧고 현재 상태를 알아보기 쉽습니다. **추천**

  | 상태 | 캡션 |
  |---|---|
  | 대기 | `Idle` |
  | 의뢰 확인 | `Reading request` |
  | 생각 중 | `Thinking` |
  | 작업 중 | `Working` |
  | 허락 대기 | `Permission requested` |

- [X] B. 아래에 직접 작성

  | 상태 | 캡션 |
  |---|---|
  | 대기 | aura farming |
  | 의뢰 확인 | chat what is this |
  | 생각 중 | lowkey cooking rn |
  | 작업 중 | locked in fr |
  | 허락 대기 | just hit approve |

- [ ] C. 위 A를 바탕으로 일부만 변경: ___

### 2. 캡션의 모양과 여백은 어떻게 할까요?

- [X] **A. 흰색 캡션 영역을 이미지와 같은 너비로 두고, 검은색 글자를 가운데 정렬** — Inter Semibold, 글자 크기 16, 캡션 영역 높이 48, 이미지와 영역 사이 간격 없음. **추천**
- [ ] B. A를 바탕으로 직접 조정: 글자 크기 ___ / 글자 굵기 ___ / 캡션 영역 높이 ___ / 이미지와 간격 ___
- [ ] C. 참고할 밈 이미지나 링크를 제공하고 그 느낌에 맞춤: ___

수치는 WPF의 화면 단위입니다. 이미지 256×256은 유지하고, 캡션 높이는 그 위에 추가됩니다.

### 3. 캡션 이외의 배경은 어떻게 할까요?

- [ ] **A. 캡션 부분만 흰색으로 두고, 이미지 영역과 위젯 바깥은 현재처럼 유지** — 이미지 자체의 배경과 투명도를 보존합니다. **추천**
- [X] B. 캡션과 이미지 뒤쪽 전체를 흰색으로 둠 — 이미지의 투명한 부분도 흰색으로 보입니다.
- [ ] C. 직접 정하기: ___

### 4. Inter 폰트는 어떻게 준비할까요?

Inter가 설치되지 않은 환경에서도 명세대로 보이게 할 방법을 선택해 주세요.

- [X] **A. 배포 가능한 Inter 폰트 파일과 필요한 라이선스 고지를 앱에 포함** — 별도 설치 없이 같은 폰트를 사용합니다. 구현 시 파일과 라이선스를 확인해야 합니다. **추천**
- [ ] B. 사용자가 Windows에 Inter를 직접 설치 — 앱에 폰트를 포함하지 않지만 설치되지 않은 환경에서는 Inter 표시를 보장할 수 없습니다.
- [ ] C. 직접 정하기: ___

### 5. 문구가 한 줄에 들어가지 않으면 어떻게 할까요?

질문 1에서 문구를 직접 정하거나 나중에 문구가 바뀌면 캡션 영역보다 길어질 수 있습니다.

- [X] **A. 글자 크기를 필요한 만큼 줄여 한 줄에 맞춤** — 문구 전체를 유지합니다. **추천**
- [ ] B. 끝을 말줄임표로 표시 — 글자 크기를 유지하지만 문구 일부가 보이지 않을 수 있습니다.
- [ ] C. 구현 시 한 줄에 들어가는 문구만 허용 — 길이가 맞지 않으면 문구를 다시 정합니다.
- [ ] D. 직접 정하기: ___
