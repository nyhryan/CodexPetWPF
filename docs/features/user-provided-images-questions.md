# 기본 GIF 제외와 사용자 이미지 등록: 결정할 질문

이 문서는 [기능 명세 초안](user-provided-images.md)을 완성하기 위한 질문입니다. 원하는 항목의 `[ ]`를 `[x]`로 바꾸거나 `1-A, 2-B`처럼 답해주세요. 직접 적거나 **“추천대로”**라고 답해도 됩니다. 추천은 제안이며 아직 확정된 내용이 아닙니다.

기존 GIF를 프로젝트 루트 `assets`에 로컬 파일로 남기되 Git과 배포물에서 제외하고, 기본 문구는 유지하며, 이미지는 사용자가 직접 등록한다는 방향은 이미 정해졌습니다. 현재 Git 추적만 해제해도 과거 커밋은 바뀌지 않습니다. 그 이력의 처리 여부는 별도로 결정합니다.

## 1. 이미지가 없는 상태에서는 무엇을 보여줄까요?

처음 실행했거나 아직 해당 상태에 이미지를 등록하지 않았을 때입니다. 기본 상태 문구는 계속 표시합니다.

- [x] **A. 이미지 영역은 기존 배경색으로 비워 둡니다.** **추천:** 별도 이미지 파일 없이 단순하게 표시합니다.
- [ ] B. 이미지 영역에 앱에서 그린 간단한 기본 모양을 표시합니다. 원하는 모양: ___
- [ ] C. 다른 방식: ___

## 2. 처음 실행했을 때 이미지 등록을 어떻게 안내할까요?

- [x] **A. 위젯에서 설정 메뉴를 사용할 수 있게 하고, 설정 화면에 이미지 추가 방법을 안내합니다.** **추천:** 처음 실행해도 곧바로 위젯을 사용할 수 있습니다.
- [ ] B. 처음 실행할 때 설정 화면을 자동으로 엽니다. 사용자가 닫거나 나중에 등록할 수 있습니다.
- [ ] C. 별도 안내 없이 사용자가 직접 설정 메뉴를 엽니다.
- [ ] D. 다른 방식: ___

## 3. 일부 상태에만 이미지를 등록해도 저장할까요?

예를 들어 대기 상태만 등록하고 나머지 네 상태는 비워 둔 경우입니다.

- [x] **A. 저장할 수 있습니다.** 이미지가 없는 상태는 1번에서 고른 방식으로 표시합니다. **추천**
- [ ] B. 다섯 상태에 모두 이미지를 등록해야 저장할 수 있습니다. 저장 전에는 기존 편집 내용을 유지하고 부족한 상태를 안내합니다.
- [ ] C. 다른 방식: ___

## 4. 초기화하면 어떻게 할까요?

현재 상태별·전체 초기화는 이미지와 문구를 모두 기본값으로 돌립니다. 기존 GIF는 더 이상 내장하지 않는다는 전제입니다.

- [x] **A. 해당 상태의 이미지 후보를 비우고 문구는 기본값으로 되돌립니다.** 저장하기 전에 확인합니다. **추천**
- [ ] B. 이미지 후보는 그대로 두고 문구만 기본값으로 되돌립니다.
- [ ] C. 이미지와 문구를 따로 초기화할 수 있게 합니다. 화면과 선택지가 늘어납니다.
- [ ] D. 다른 방식: ___

## 5. 이전에 저장한 설정은 어떻게 바꿀까요?

기존 설정에는 기본 GIF를 가리키는 `asset:` 항목과 사용자가 추가한 이미지, 문구가 섞여 있을 수 있습니다. 어떤 선택이든 **사용자 이미지 사본과 사용자 지정 문구는 유지**합니다.

- [x] **A. `asset:` 항목만 목록에서 제외하고, 설정 화면에 기본 이미지가 제거되었다는 안내를 표시합니다.** 사용자 이미지가 없어진 상태는 1번 방식으로 표시합니다. **추천**
- [ ] B. `asset:` 항목을 제외하되 별도 안내는 표시하지 않습니다.
- [ ] C. 다른 방식: ___

설정을 불러오는 것만으로 파일을 덮어쓸지, 사용자가 다음에 저장할 때 변경할지는 구현 시 결정합니다. 어떤 경우에도 사용자 이미지 파일을 지우지 않는 방향입니다.

## 6. 등록한 이미지 중 일부를 읽을 수 없으면 어떻게 할까요?

- [x] **A. 읽을 수 있는 다른 후보가 있으면 그 후보를 사용하고, 없으면 1번 방식으로 표시합니다.** 설정 화면에서 읽지 못한 항목을 안내합니다. **추천**
- [ ] B. 해당 상태의 이미지 영역을 1번 방식으로 표시하고 설정 화면에서 안내합니다.
- [ ] C. 다른 방식: ___

## 답변 후 반영할 내용

- 이미지 없는 상태의 화면과 등록 안내, 일부 상태만 등록했을 때의 저장 규칙.
- 초기화, 기존 `asset:` 참조와 사용자 설정 보존, 이미지 읽기 실패 시 동작.
- [기능 명세](user-provided-images.md) 및 기존 상태 표시·설정 메뉴 명세와 Spec 1의 관련 완료 기준.
