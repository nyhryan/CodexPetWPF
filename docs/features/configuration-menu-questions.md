# 설정 메뉴: 명세를 완성하기 위한 질문

이 문서는 [설정 메뉴 초안](configuration-menu.md)을 함께 구체화하기 위한 메모입니다. 원하는 항목의 `[ ]`를 `[x]`로 바꾸거나, `1-A, 2-B`처럼 번호와 답을 알려주세요. 자유롭게 적거나 «추천대로»라고 답해도 됩니다. **추천은 논의를 위한 제안이며 아직 확정된 내용은 아닙니다.**

## 현재 확인한 내용

- 설정할 상태는 기존 [상태 표시 명세](show-state-widget.md)의 대기, 의뢰 확인, 생각 중, 작업 중, 허락 대기 다섯 가지입니다. 현재 상태마다 이미지와 문구가 하나씩 있습니다.
- 위젯은 대기 상태로 시작합니다. 같은 상태에 해당하는 이벤트가 이어지면 이미지를 바꾸거나 GIF를 다시 시작하지 않습니다. 우클릭 메뉴에는 종료 항목이 있습니다.
- 현재 이미지는 GIF이며 계속 반복 재생합니다. 이미지는 256×256 영역에 비율을 유지하며 들어가고, 문구는 한 줄에 표시하며 길면 크기를 줄입니다.
- 새 초안의 의도는 상태별로 이미지와 문구를 여러 개 설정하고, 실행 중에도 변경하며, 기본 설정은 현재 모습으로 유지하는 것입니다.

- [ ] C. 같은 상태의 이벤트를 포함해 이벤트가 올 때마다 다시 고릅니다.

## 답변을 바탕으로 명세에 추가할 내용

- 대상 상태와 기본 후보, 후보 추가·수정·삭제·초기화 방법.
- 후보를 고르는 단위와 시점, 시작할 때와 같은 상태의 이벤트가 이어질 때의 동작.
- 설정 적용·저장·취소, 재실행 후 유지, 설정 중 이벤트 수신 및 현재 표시 갱신 방식.
- 지원 이미지 형식과 보관 방식, GIF 재생, 이미지와 문구의 표시·입력 조건.
- 읽기·저장 실패 시 안내와 복구 방법.
- 선택한 정책을 검증할 완료 기준: 기본 설정, 여러 후보, 실행 중 변경, 재실행과 오류 상황.

## 추가 사항

위젯 우클릭 메뉴의 현재 디자인이 `[   |  메뉴 이름 ]` 와 같이 왼쪽에 빈 공간이 있고, 구분선이 있고, 그 다음에 메뉴 명이 있어. 이런 디자인 말고 깔끔한 디자인으로 하고 싶어.
