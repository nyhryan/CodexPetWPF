## 설정 메뉴

### 목적

사용자가 Codex의 상태를 나타내는 이미지와 문구를 상태별로 원하는 만큼 등록하고, 실행 중에도 변경할 수 있다.

### 설정 대상과 기본값

설정할 상태는 기존 [상태 표시 명세](show-state-widget.md)의 다섯 가지다. 최초 설정에서는 이미지 후보가 없으며 아래 문구를 각 상태의 유일한 문구 후보로 사용한다.

| 상태 | 기본 문구 |
|---|---|
| 대기 | `AURA FARMING` |
| 의뢰 확인 | `CHAT WHAT IS THIS` |
| 생각 중 | `LOWKEY COOKING RN` |
| 작업 중 | `LOCKED IN FR` |
| 허락 대기 | `JUST HIT APPROVE` |

- 각 상태에 이미지와 문구를 각각 여러 개 등록한다. 이미지와 문구는 짝으로 묶지 않는다.
- 기본 문구도 후보 목록에 표시하며 삭제할 수 있다. 삭제하기 전까지는 다른 후보와 함께 선택 대상에 남는다. 기본 이미지는 제공하지 않는다.
- 이미지 후보가 없는 상태가 있어도 저장할 수 있다. 문구 후보는 상태마다 한 개 이상 있어야 저장할 수 있으며, 빈 문구도 등록된 문구 후보 한 개로 취급한다.

### 후보 선택과 상태 표시

- 위젯 시작 시 저장된 대기 상태의 문구와 읽을 수 있는 이미지 후보를 각각 무작위로 선택한다. 읽을 수 있는 이미지가 없으면 이미지 영역을 비운다.
- 다른 상태로 전환할 때마다 해당 상태의 문구와 읽을 수 있는 이미지 후보를 각각 무작위로 선택한다. 이미지가 없으면 이미지 영역을 비운다. 등록된 이미지와 문구는 어떤 조합으로도 표시될 수 있으며, 이전과 같은 후보가 다시 선택될 수도 있다.
- 같은 상태에 해당하는 이벤트가 연속해서 오면 후보를 다시 선택하거나 GIF를 다시 시작하지 않는다.
- 상태 전환과 이벤트 처리의 나머지 규칙은 기존 [상태 표시 명세](show-state-widget.md)를 따른다.

### 설정 화면과 우클릭 메뉴

- 위젯 우클릭 메뉴에서 설정 화면을 연다. 기존 종료 항목도 유지한다.
- 우클릭 메뉴에서 메뉴 이름 왼쪽의 빈 아이콘 영역과 그 영역의 세로 구분선이 보이지 않도록 한다. 설정과 종료 항목 사이에는 기존과 같이 가로 구분선을 표시하지 않는다.
- 설정 화면에서 상태를 선택하고 해당 상태의 이미지 및 문구 후보를 목록으로 확인·추가·삭제할 수 있다. 이미지 추가 방법을 안내한다. 이해하기 쉽고 사용하기 편한 UI 컴포넌트를 사용한다.
- 상태별 초기화와 전체 초기화를 제공한다. 초기화 실행 전에 확인을 받으며, 초기화하면 해당 상태의 이미지 후보는 비우고 문구 후보는 위 표의 기본 문구로 되돌린다.
- 초기화를 포함한 설정 변경은 저장하기 전까지 편집 중인 내용이다.

### 적용과 저장

- 설정 화면의 ‘저장’을 누르면 변경 내용을 적용하고, 앱을 다시 실행해도 유지한다.
- ‘취소’하거나 저장하지 않고 설정 화면을 닫으면 저장하지 않은 변경을 버린다.
- 현재 표시 중인 상태의 설정을 변경하고 저장하면 해당 상태의 표시를 바로 갱신한다. 다른 상태의 변경은 그 상태가 다음에 표시될 때 반영한다.
- 설정 화면이 열려 있는 동안에도 Codex 상태 이벤트는 평소처럼 처리한다. 편집 중인 내용은 저장 전까지 위젯에 적용하지 않는다.

### 이미지와 문구

- 파일 선택으로 GIF, PNG, JPEG 이미지를 추가한다. 앱이 이미지 사본을 보관하므로 원본 파일을 이동하거나 삭제해도 저장된 이미지를 사용할 수 있다.
- GIF는 무한 반복한다. 반복 횟수 설정은 제공하지 않는다.
- 이미지는 기존과 같이 256×256 WPF 화면 단위 영역 안에 비율을 유지해 전체가 보이도록 표시한다. 여백과 투명한 부분에는 기존의 옅은 회색 배경이 보인다.
- 문구는 한글과 영문 등을 입력한 그대로 표시한다. 별도의 글자 수 제한은 두지 않으며, 기존과 같이 한 줄에 표시하고 길면 크기를 줄인다.
- 빈 문구나 공백만 있는 문구도 등록할 수 있다. 해당 후보가 선택되면 문구를 표시하지 않는다.

### 오류 처리

- 지원하지 않거나 읽을 수 없는 이미지는 등록하지 않고 이유를 알린다.
- 앱 시작이나 표시 중 이미지 후보를 읽지 못하면 설정 화면에 문제를 알리고 읽을 수 있는 다른 후보를 사용한다. 정상 이미지 후보가 없으면 이미지 영역을 비운다. 설정을 읽지 못한 항목은 기본 문구와 빈 이미지 영역을 사용하고 문제를 알린다. 읽을 수 있는 정상 설정은 계속 사용한다.
- 이전 설정의 `asset:` 기본 이미지 후보는 제외하고 설정 화면에 제거 안내를 표시한다. 사용자 이미지 사본과 사용자 지정 문구는 유지한다. 자세한 내용은 [사용자 이미지 명세](user-provided-images.md)를 따른다.
- 설정 저장에 실패하면 실패를 알리고 설정 화면과 편집 내용을 유지해 다시 시도할 수 있게 한다.

### 완료 기준

- 처음 실행하면 이미지 영역은 비어 있고 다섯 상태는 각각 기본 문구를 표시한다. 위젯 우클릭 메뉴에서 설정과 종료를 사용할 수 있으며 설정 화면에서 이미지 추가 방법을 안내한다. 메뉴 왼쪽에 빈 아이콘 영역이나 세로 구분선이 없고, 항목 사이에도 가로 구분선이 없다.
- 각 상태에서 이미지와 문구를 따로 추가·삭제할 수 있고, 기본 문구도 삭제할 수 있다. 이미지 후보가 없어도 저장할 수 있으며 문구 후보가 없는 상태가 있으면 저장할 수 없고 이유가 표시된다.
- 상태가 바뀔 때 이미지와 문구를 각각 후보에서 고른다. 같은 상태의 이벤트가 이어지면 선택과 GIF 재생을 유지하고, 재시작 시에는 저장된 대기 후보에서 선택한다.
- 저장한 설정은 즉시 적용되고 재실행 후에도 유지된다. 현재 표시 중인 상태를 수정해 저장하면 표시가 갱신되며, 취소하거나 저장하지 않고 닫은 수정은 반영되지 않는다.
- 설정 화면을 열어 둔 상태에서도 Codex 이벤트에 따른 상태 전환이 동작한다.
- GIF·PNG·JPEG를 등록할 수 있고 원본을 옮기거나 삭제해도 보관한 사본을 표시한다. GIF는 무한 반복하며, 이미지 비율과 배경은 기존 표시 규칙을 따른다.
- 한글, 소문자, 빈 문구와 공백만 있는 문구를 등록할 수 있다. 빈 문구나 공백만 있는 문구가 선택되면 문구가 표시되지 않는다.
- 상태별 또는 전체 초기화 전에 확인하고, 저장 후 대상의 이미지 후보는 비고 문구는 기본값으로 돌아간다.
- 이미지를 읽거나 설정을 저장하는 데 실패했을 때 오류를 알리고 위의 오류 처리 규칙에 따라 동작한다.
