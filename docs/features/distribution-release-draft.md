# CodexPet 0.1.0 릴리스 안내 초안

**초안 — 아직 공개 승인이나 최종 파일 확정이 되지 않았다.** 공개 전 이 문서의 미확정 항목을 실제 결과로 바꾸고 Spec 2·3·4의 검증을 완료한다.

CodexPet은 Windows에서 로컬 Codex의 작업 상태를 위젯으로 표시한다. 이미지와 문구는 사용자가 직접 설정한다.

- 지원 대상: Windows 11 x64의 로컬 Codex. 정확한 검증 버전·에디션: **미확정**.
- 다운로드: `CodexPet-Setup-0.1.0-win-x64.exe` — 2026-11-10 GitHub 저장소 `nyhryan/CodexPetWPF`의 메타데이터는 공개 상태다. 릴리스와 파일의 비로그인 접근성은 **미확인**이다.
- 설치·훅 신뢰·제거 및 문제 해결: [설치 안내](installation-guide.md). 설치 후 사용자가 Codex에서 훅을 검토하고 신뢰해야 한다.
- 주요 변경: 첫 0.1.0 배포 준비. 위젯 표시·사용자 이미지와 문구 설정·사용자별 설치 및 전역 훅 등록/제거.
- 제한: Windows ARM64, WSL, 원격·클라우드 작업은 이 버전의 대상이 아니다. 자동 업데이트와 자동 시작은 제공하지 않는다. 여러 세션의 상태는 도착한 이벤트 순서대로 표시된다. 보안 검토 및 나머지 제한은 최종 검증 후 갱신한다.
- 설치 파일은 **서명되지 않았다**. Windows에서 게시자 미확인 또는 SmartScreen 경고가 나타날 수 있다. 공식 배포 위치와 해시를 확인하고, 해시가 게시자 신원까지 증명하는 것은 아님을 안내한다.
- 최종 파일 SHA-256: **최종 파일 확정 후 기입**. PowerShell에서 `Get-FileHash -Algorithm SHA256 <다운로드한 파일 경로>`로 비교한다.
