# CodexPet

## 목표
Codex의 작업 상태를 위젯 형태의 애플리케이션에서 보여준다. 각 상태에 대응되는 정적 이미지나 GIF 이미지를 보여준다.

## 대상 사용자
Windows 데스크톱에서 Codex를 사용하는 개인 사용자

## 첫 버전의 범위
- Codex 이벤트에 따라 사전 설정 된 이미지를 표시한다.
- 위젯 창을 드래그하여 움직일 수 있다.
- 위젯 창 위에서 우클릭 메뉴를 통해 위젯을 종료할 수 있다. 닫기 버튼을 가진 상단바를 표시하지 않는다.

## 첫 버전에서 제외
- 설정 메뉴를 통해 사용자 지정 이미지를 대신 사용할 수 있다.
- 위젯 창은 다른 창보다 항상 위에 표시된다.

## 기본 제약
- Windows 데스크톱 앱으로 동작한다.
- 펫을 사용할 수 없는 상황에서도 Codex 작업은 계속된다.
- GIF 이미지는 무한 반복한다. 반복 횟수 지정은 프로젝트 범위에 포함하지 않는다.
